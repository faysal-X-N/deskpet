## 1. 项目概述与目标

### 1.1 项目名称

**桌面宠物** — 一款 Android 悬浮窗桌面宠物应用。

### 1.2 一句话描述

在手机屏幕上养一只会互动的小宠物：它能浮在任何 App 上方，你点它它会招手，拖它可以移动，偶尔还会自己走走跳跳。

### 1.3 目标用户

- 喜欢桌面宠物的普通手机用户
- 不需要编程知识，手动导入素材即可使用

### 1.4 核心价值

- 情感陪伴：宠物可以互动，不是死板的图片
- 自由定制：支持导入 Codex Pet 社区 2500+ 宠物，以及 GIF 动图
- 轻量无打扰：悬浮窗形式，不干扰正常使用手机

## 2. 功能需求

### 2.1 核心功能（必须实现 — 不做这些系统不算完成）

| 编号 | 功能 | 说明 |
|------|------|------|
| **F-01** | 悬浮窗显示 | 宠物以悬浮窗形式显示在手机屏幕上，覆盖在其他 App 上方。需要申请 `SYSTEM_ALERT_WINDOW` 权限。 |
| **F-02** | 触摸交互 — 点击反应 | 点击宠物时，宠物播放 waving（招手）动画（遵循 Codex Pet 标准规范）。
| **F-03** | 触摸交互 — 拖拽移动 | 拖拽宠物可移动屏幕位置。**Codex Pet 宠物**：拖拽方向触发对应动画（左→running-left、右→running-right、上→jumping、下→waving），松手后恢复 idle。**GIF 宠物**：仅移动位置，不切换动画。 |
| **F-04** | 双指缩放 | 用两根手指捏合/扩张可以调整宠物的大小。 |
| **F-05** | 宠物栏选择器 | 提供一个「宠物栏」界面，展示所有已导入的宠物列表，点击即可切换当前显示的宠物。同一时间屏幕上只显示 1 只。 |
| **F-06** | 手动导入宠物 | 支持两种导入模式：① Codex Pet 标准包（spritesheet.webp/.png + pet.json），按 8列×9行精灵表解析动画；② 普通 GIF 动图，直接循环播放，不区分动画状态。 |
| **F-07** | 宠物自主行为 | 宠物在未被触摸时，每隔随机间隔从 idle（发呆）自动切换到 running（散步）、jumping（蹦跳）、waiting（东张西望）、review（歪头观察）之一，播放后回到 idle。模拟活物感。 |

### 2.2 扩展功能（有时间可以做，不影响核心交付）

| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| **E-01** | 在线浏览下载 | 在 App 内浏览 Petdex 宠物列表并一键下载安装 | 低 |
| **E-02** | 宠物删除管理 | 在宠物栏中长按删除已导入的宠物 | 中 |
| **E-03** | 宠物命名 | 为导入的宠物自定义名称 | 低 |
| **E-04** | 开机自启 | 手机开机后宠物自动出现在屏幕上 | 低 |
| **E-05** | 多只同屏 | 同时显示多只宠物在屏幕上 | 低 |
| **E-06** | 复杂交互 | 双击喂食、滑动抚摸等更多交互方式 | 低 |
| **E-07** | 暗色主题 | App 界面支持暗色模式 | 低 |

## 3. 非功能需求

### 3.1 性能要求

| 指标 | 要求 | 说明 |
|------|------|------|
| 帧率 | 60 FPS | 宠物动画流畅丝滑 |
| 内存占用 | 无硬性限制 | 正常使用即可，不拖慢手机 |
| CPU 占用 | 无硬性限制 | 静置时尽量低，不异常发热 |
| 启动时间 | ≤ 2 秒 | 从点击图标到宠物显示 |
| 电池消耗 | 无硬性限制 | 正常使用即可 |

### 3.2 兼容性要求

| 项目 | 要求 |
|------|------|
| 最低系统版本 | Android 8.0（API 26） |
| 目标系统版本 | Android 14（API 34） |
| 屏幕方向 | 竖屏 + 横屏均支持 |
| 分辨率适配 | 支持常见手机分辨率（720p ~ 1440p） |
| 权限要求 | 悬浮窗权限（`SYSTEM_ALERT_WINDOW`） |

### 3.3 可用性要求

- App 界面语言：仅中文
- 导入操作步骤：≤ 3 步完成一只宠物的导入
- 切换宠物操作：≤ 2 步完成切换
- 首次使用引导：提供简单的操作指引

### 3.4 安全与隐私

- 不需要联网权限（纯本地运行）
- 不收集任何用户数据
- 悬浮窗仅在用户主动开启时显示

### 3.5 素材格式支持

| 格式 | 说明 |
|------|------|
| **Codex Pet 标准包** | 包含 `spritesheet.webp`（或 `.png`）+ `pet.json`。spritesheet 为 8列×9行 精灵表（1536×1872px，每帧 192×208px）。9 行对应固定动画状态（见下表）。 |
| **GIF 动图** | 直接导入 `.gif` 文件，循环播放动图内容。不做 spritesheet 解析，不支持动画状态切换。点击时仅做物理弹跳反馈，不切换动画。 |

### 3.6 Codex Pet 标准动画状态（9 行）

| 行号 | 状态名 | 含义 | 触发场景 |
|------|--------|------|----------|
| 0 | `idle` | 待机/发呆 | 静止不动时默认状态 |
| 1 | `running-right` | 向右跑 | 向右拖拽时 |
| 2 | `running-left` | 向左跑 | 向左拖拽时 |
| 3 | `waving` | 招手 | 点击时、向下拖拽时 |
| 4 | `jumping` | 跳跃 | 向上拖拽时 |
| 5 | `failed` | 沮丧 | （保留，暂不使用） |
| 6 | `waiting` | 等待 | 自主行为：东张西望 |
| 7 | `running` | 跑动 | 自主行为：散步 |
| 8 | `review` | 观察 | 自主行为：歪头观察 |

### 3.7 行为规范

- **悬浮窗生命周期**：悬浮窗跟随 App 生命周期。App 被强制关闭（多任务界面划掉）后，悬浮窗也消失。
- **位置/大小记忆**：切换宠物后，每只宠物的屏幕位置和缩放比例分别记忆，切回时恢复。
- **悬浮窗权限**：首次使用时引导用户授权 `SYSTEM_ALERT_WINDOW` 权限，未授权则不显示宠物。

### 4.1 输入

| 输入 | 格式 | 说明 |
|------|------|------|
| Codex Pet 素材包 | 文件夹或 .zip，内含 spritesheet + pet.json | 用户通过系统文件选择器选择 |
| GIF 动图 | .gif 文件 | 用户通过系统文件选择器选择 |

### 4.2 输出

| 输出 | 说明 |
|------|------|
| 悬浮窗宠物动画 | 渲染 Codex Pet spritesheet 精灵表动画或 GIF 循环动画，支持 9 种标准动画状态切换 |
| 触摸反馈效果 | 点击→waving 动画；拖拽→方向对应动画（左/右/上/下→running-left/running-right/jumping/waving）+ 位置移动 |

## 7. 术语表

| 术语 | 说明 |
|------|------|
| **Codex Pet** | 一种开源桌面宠物标准格式，由一个透明 spritesheet 图片 + 一个 pet.json 配置文件组成 |
| **Spritesheet** | 精灵表，一张包含宠物所有动画帧的图片，每个动画状态占一行 |
| **pet.json** | Codex Pet 的配置文件。定义宠物 ID、名称、spritesheet 路径，以及可选的动画状态映射。标准 9 行动画状态：idle / running-right / running-left / waving / jumping / failed / waiting / running / review |
| **悬浮窗** | Android 的 `TYPE_APPLICATION_OVERLAY` 窗口，可以浮在其他 App 上方 |
| **宠物栏** | App 内展示所有已导入宠物的选择界面 |
| **GIF 宠物** | 通过普通 GIF 动图导入的宠物。直接循环播放，不解析 spritesheet，不区分动画状态。点击仅做物理弹跳反馈。 |
