### 一、安装指南

#### 1.1 获取安装包

从 [Releases 页面](../../releases) 下载最新版本的 APK 安装包（文件名为 `app-debug.apk` 或类似名称）。

#### 1.2 安装步骤

1. 在手机上找到下载的 APK 文件，点击打开
2. 如果系统提示「禁止安装未知来源应用」，请根据提示进入系统设置，**允许「桌面宠物」或「文件管理器」安装未知应用**

#### 1.3 卸载方法

长按桌面上的「桌面宠物」图标 → 选择「卸载」即可。卸载后，所有宠物数据（包括您导入的素材）将被一并删除。

### 二、首次使用

#### 2.1 权限引导

首次打开应用时，会弹出「欢迎使用桌面宠物」对话框，显示基本操作说明。点击「知道了」关闭对话框。

#### 2.2 悬浮窗权限（核心步骤）

宠物需要「悬浮窗」权限才能在屏幕上显示。操作流程如下：

1. 在宠物栏中点击「**开启**」按钮
2. 如果尚未授予悬浮窗权限，应用会自动跳转到权限设置页面
3. 找到「桌面宠物」→ 打开「允许显示在其他应用的上层」开关
4. 返回应用 → **自动开启悬浮窗**，无需再点一次「开启」

> Android 13 及以上首次开启时还会询问「通知」权限，允许后通知栏会显示常驻通知（关闭通知不影响宠物显示，只是通知栏看不到运行状态）。

> **各品牌手机路径参考**：
>
> | 品牌 | 权限设置路径 |
> |------|------------|
> | 小米/红米 (MIUI) | 设置 → 应用设置 → 应用管理 → 桌面宠物 → 权限管理 → 显示悬浮窗 |
> | 华为/荣耀 (EMUI) | 设置 → 应用 → 应用管理 → 桌面宠物 → 权限 → 设置单项权限 → 悬浮窗 |
> | OPPO (ColorOS) | 手机管家 → 权限隐私 → 悬浮窗管理 → 桌面宠物 |
> | vivo (OriginOS) | 设置 → 安全与隐私 → 权限管理 → 权限 → 悬浮窗 → 桌面宠物 |
> | 三星 (OneUI) | 设置 → 应用程序 → 右上角"⋮" → 特殊访问 → 在其他应用上层显示 → 桌面宠物 |
> | 原生 Android | 设置 → 应用和通知 → 特殊应用权限 → 在其他应用上层显示 → 桌面宠物 |

#### 2.3 示例宠物

首次启动后，应用会自动加载内置的原创示例宠物**橘团**（一只像素橘猫），无需额外导入即可体验。

> **关于其他示例宠物**：v1.1.1 及更早版本还内置过胡桃、芙宁娜、飞雪、伊坤等 Codex Pet 社区素材包。为避免把第三方角色形象随 APK 分发（版权风险 + 开源商店审核拒收理由），v1.2.0 起只保留本项目原创的「橘团」。想要这些宠物，用「导入 Codex Pet 素材包」自己导入即可，效果与内置完全一致，格式没有任何限制。

### 三、日常操作

#### 3.1 开启宠物

1. 打开「桌面宠物」应用
2. 在宠物列表中点击想要显示的宠物（当前选中会有弹簧缩放的阴影效果）
3. 点击「**开启**」按钮
4. 宠物出现在手机屏幕上方悬浮窗中

#### 3.2 与宠物互动

| 操作 | 效果 | 适用类型 |
|------|------|----------|
| **单击** | 宠物播放招手动画 | Codex Pet |
| **单击** | 宠物做弹跳动作 | GIF 宠物 |
| **长按后拖拽** | 移动宠物到任意位置 | 全部类型 |
| **拖拽方向** | 向左拖→向左跑 / 向右拖→向右跑 / 向上拖→跳跃 / 向下拖→招手 | 仅 Codex Pet |
| **双指捏合/扩张** | 放大或缩小宠物 | 全部类型 |
| **不做任何操作** | 约 30 秒后，宠物自己散步、蹦跳、东张西望 | 仅 Codex Pet |

#### 3.3 关闭宠物

- **方法一**：回到「桌面宠物」应用，点击「**关闭**」按钮
- **方法二**：下拉通知栏，点击常驻通知上的「**关闭宠物**」按钮

**关于「划掉后台」**：

- 原生 Android 上，应用被划掉后**宠物仍会保留在屏幕上**，继续浮在其他应用上方
- 部分国产系统（小米、OPPO、vivo 等）的「一键清理 / 上滑清理」会连前台服务一起强杀，宠物可能消失。规避方法：最近任务里长按本应用卡片**锁定**、省电策略设为「**无限制**」、允许**自启动**（详见 Q2）
- 万一宠物被系统清理，**重新打开「桌面宠物」应用会自动把宠物唤回**，无需手动点「开启」；您主动关闭的宠物不会被「复活」
- 注意：仅按 Home 键回到桌面，宠物不会消失，会继续浮在其他应用上方

#### 3.4 切换宠物

在宠物栏中点击另一只宠物即可**直接切换**，不需要先关闭。每只宠物的屏幕位置和缩放比例是**独立记忆**的，切换回来时会恢复上次的位置和大小。

#### 3.5 调整宠物大小

有两种方式：

- **方式一（精确）**：在宠物栏的缩放卡片中**拖动滑块**（50% ~ 500%），或点击 **− / +** 按钮以 10% 步进微调，点击 **↺** 一键恢复 100%；滑块旁的百分比胶囊实时显示当前比例
- **方式二（自由）**：在屏幕上直接用**两根手指**捏合或扩张悬浮窗中的宠物

### 四、导入自定义宠物

本应用支持两种宠物格式：

#### 4.1 导入 Codex Pet 素材包（推荐，有动画）

Codex Pet 是一种开源桌面宠物标准，一个素材包包含：
- `pet.json` — 宠物配置文件（名称、动画帧定义等）
- `spritesheet.webp` 或 `spritesheet.png` — 精灵表图片（8列×9行动画帧）

**导入步骤**：

1. 从 [Codex Pet 社区](https://github.com/Codexdei/petdex) 或其他来源下载 `.zip` 格式素材包
2. 打开「桌面宠物」应用
3. 点击「**导入**」→「**🎨 导入 Codex Pet 素材包**」
4. 在文件选择器中找到并选择下载的 zip 文件
5. 导入成功后，宠物出现在宠物栏中，可以正常使用

> **Codex Pet 支持的 9 种动画状态**：
>
> | 状态 | 说明 | 触发时机 |
> |------|------|----------|
> | idle | 待机/发呆 | 静止不动时默认状态 |
> | running-right | 向右跑 | 向右拖拽时 |
> | running-left | 向左跑 | 向左拖拽时 |
> | waving | 招手 | 点击宠物时 |
> | jumping | 跳跃 | 向上拖拽时 |
> | waiting | 东张西望 | 自主行为触发 |
> | running | 散步 | 自主行为触发 |
> | review | 歪头观察 | 自主行为触发 |
> | failed | 沮丧 | 保留（暂未启用） |

#### 4.2 导入 GIF 动图（简单，无动画切换）

**导入步骤**：

1. 准备一个 `.gif` 动图文件（建议尺寸不超过 500×500 像素，文件不超过 10MB）
2. 打开「桌面宠物」应用
3. 点击「**导入**」→「**📷 导入 GIF 动图**」
4. 在文件选择器中选择 GIF 文件
5. 导入成功后，宠物出现在宠物栏中

> **GIF 宠物说明**：
> - GIF 宠物仅循环播放动图内容，不会像 Codex Pet 那样区分不同动画状态
> - GIF 以约 5FPS 播放（与 Codex Pet 动画帧率一致），并非原始 GIF 的全部帧率
> - 点击 GIF 宠物会做一个弹跳效果，不会切换动画
> - 拖拽 GIF 宠物只会移动位置，不会切换动画
> - 如果 GIF 动图过大（超过 10MB），导入时会提示文件过大并拒绝导入

#### 4.3 重复导入检测

如果您尝试导入的设备上已经存在的宠物（通过 `sourceId` 判断：Codex Pet 用素材包配置里的 id，GIF 用「文件名 + 文件大小」），应用会提示「该宠物已存在」，**不会重复导入**，避免浪费存储空间。

### 五、宠物管理

#### 5.1 删除宠物

1. 在宠物栏中**长按**要删除的宠物卡片
2. 弹出确认对话框，点击「删除」确认
3. 该宠物的素材文件和配置将被**永久删除**，无法恢复

> **注意**：删除正在显示的宠物会先自动关闭悬浮窗，再删除素材文件。

#### 5.2 导出单个宠物

点击宠物卡片右下角的 **分享图标**（↗），可将该宠物的素材打包为 zip 文件导出，方便分享给朋友或转移到其他设备。

#### 5.3 备份全部宠物

1. 点击右上角「**⋮**」菜单
2. 选择「**💾 备份全部**」
3. 系统生成一个 `DeskPet_backup.zip` 文件，包含所有宠物数据和素材
4. 通过系统分享菜单发送到微信、QQ、网盘等处保存

#### 5.4 恢复备份

1. 打开「桌面宠物」→ 点击「**导入**」→「**💾 恢复备份**」
2. 选择之前导出的 `.zip` 备份文件
3. 恢复完成，所有宠物回到宠物栏中
4. 已存在的宠物（通过 ID 判断）会被**自动跳过**，不会重复

> **换机迁移**：在新手机上安装本应用 → 将旧手机导出的 `DeskPet_backup.zip` 传到新手机 → 使用「恢复备份」功能 → 所有宠物一键迁移完成。

### 六、常见问题

#### Q1：点击「开启」后宠物不出现？

1. 检查是否授予了悬浮窗权限（见第二章 §2.2）
2. 部分手机需要在手机管家/安全中心中允许「桌面宠物」后台运行
3. 尝试重启应用后再次点击「开启」

#### Q2：宠物过一会儿就自己消失了？

这是国产手机（小米、华为、OPPO、vivo 等）的后台管理策略导致的。解决方法：

- **小米**：设置 → 应用设置 → 桌面宠物 → 省电策略 → 选择「无限制」
- **华为**：手机管家 → 启动管理 → 桌面宠物 → 允许自启和后台活动
- **OPPO**：设置 → 电池 → 应用耗电管理 → 桌面宠物 → 允许后台运行
- **vivo**：i管家 → 应用管理 → 权限管理 → 自启动 → 桌面宠物

#### Q3：导入宠物时提示「格式错误」？

- 确认 Codex Pet 素材包是 `.zip` 格式，且包含 `pet.json` 和 spritesheet 图片
- 确认 GIF 文件是真正的 GIF 格式（不是改了后缀名的其他图片）
- 尝试重新下载素材包

#### Q4：为什么我的宠物不会换动作？

只有 Codex Pet 格式的宠物支持多动画状态切换。GIF 动图导入的宠物仅循环播放，不会响应拖拽方向或自主行为来切换动画。

#### Q5：切换宠物后显示的还是旧宠物？

当前版本支持**运行中直接切换**：在宠物栏点击另一只宠物即可，无需先关闭悬浮窗。如果切换没有生效，请先点「关闭」再点「开启」重试。

#### Q6：应用会消耗很多电量吗？

本应用已做多项性能优化：帧解码在后台 IO 线程执行、GPU 硬件加速渲染、最低帧间隔保护、系统**省电模式**下自动降低帧率并暂停自主行为。宠物静止时（idle 状态）CPU 占用极低。如果您发现异常耗电，可以在不需要宠物时点击「关闭」来停止悬浮窗服务。

- 📦 **Codex Pet 兼容** — 支持社区 2500+ 宠物素材包导入

## 📋 已知限制

| 限制 | 说明 | 影响范围 |
|------|------|----------|
| ROM 强杀服务 | MIUI / ColorOS / OriginOS 等的「一键清理」会连前台服务一起杀，宠物可能消失 | 需锁定任务卡片 + 省电白名单（见 Q2）；被清理后重新打开应用可自动恢复 |
| 通知权限 | Android 13+ 未授予通知权限时看不到常驻通知（宠物仍正常显示） | 仅影响通知栏状态展示 |
| 单只显示 | 同一时间屏幕上只能显示 1 只宠物 | 多只同屏功能规划中 |
| 开机不启动 | 手机重启后需要手动打开应用 | 已规划开机自启功能 |
| GIF 帧率 | GIF 以约 5FPS 播放，不跟随原始动图帧率 | 快速动画会显得卡顿 |
| 低端设备 | API 26 设备上 spritesheet 采用全量解码，内存占用约 11MB | 影响极小（该版本设备占比 <2%） |
